## Consolidated Decision Summary

### Dividend Portfolio — Phase 1 MVP Architecture

**Approved Design:** Ledger-first dividend portfolio with independent Cosmos container, multi-currency, dual-layer withholding, support for mixed cash/share dividends.

**Key Decisions (Authoritative):**

1. **Domain Separation:** Portfolio movements (BUY/SELL/DIVIDEND) in new `portfolio` container; watchlist flags remain in `symbols` container. Link via ticker symbol string, not foreign key.

2. **Ledger-First Model:** All movements append-only; corrections via soft-delete or new movement. No mutable "current position" document. Holdings always derived: `Σ(buys) - Σ(sells) + Σ(dividend_shares)`.

3. **Multi-Currency & FX:** Every amount stored in transaction currency AND EUR equivalent. FX rates stored as decimal strings (9 dp), convention: `rate = txn_currency / EUR`, always multiply to get EUR.

4. **Broker Identity:** Four profiles (Fidelity, HeyTrade, ING, Interactive Brokers) with distinct withholding/FX/fee patterns. Profiles are behavior hints in forms; stored facts override.

5. **Withholding Dual-Layer:** Source (country-of-security withholding, e.g. US 15%) and destination (investor's country, e.g. Spain 19%) both modeled. **Critical:** `withholding_destination = null` (broker doesn't capture) ≠ `{amount: 0}` (confirmed zero). UI renders null as ⚠️ "Pending".

6. **Mixed Dividends (Scrip/DRIP):** Optional stock leg on DIVIDEND movement. Atomic submission; both legs created together. Cost basis can be zero (true scrip) or fair value (elected in-lieu).

7. **Navigation:** New "Portfolio" top-level menu between Economics and Chat. Four subpages: Securities (holdings), Movements (ledger), Dividends (yield focus), Accounts (broker setup). No rename of Symbols/Watchlist.

8. **Cost Basis Method (MVP):** Average cost (simplest, matches Spanish FIFO-like scenarios). FIFO/LIFO deferred to Phase 3.

9. **Phased Migration of total_shares:** Phase 1 coexists with existing `symbol_config.total_shares`. Phase 2 Excel import + reconciliation tool. Phase 3 derive from ledger.

10. **Security Identity (ISIN):** All transactions carry ISIN (canonical), plus secondary IDs (CUSIP, SEDOL, ticker, exchange MIC). Security object embedded in every movement (denormalized for performance).
